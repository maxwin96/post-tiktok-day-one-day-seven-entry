A 20-second vertical TikTok video about ORB RUSH, a tiny orb-collector game my AI agent built in one HTML5 canvas file. The video cuts between identical moments of the same game on day one and day seven: same map, same start, same scripted run, a camera that never moves — so the change is the whole story. Day one is quiet: 6 orbs, one slow enemy, a score stuck at zero. Day seven is the same moment exploding: 24 orbs, five enemies (one of them chasing), power-up stars, a ×2 multiplier, particle trails, a combo counter and three hearts — the score races to 120 while the player barely survives. It closes on the day-seven build being played, the line "start yours at make.fun", and make.fun's referral end card with my code typed in.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `VIDEO.json` (the TikTok video's address) into the output directory. That is all it does.
